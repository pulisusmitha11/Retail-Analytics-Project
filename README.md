\# End-to-End Retail Analytics Project Using Python



\## Project Overview

This project analyzes online retail sales data using Python to understand sales performance, customer activity, popular products, and country-wise revenue.



\## Objectives

\- Clean and prepare retail transaction data.

\- Calculate total sales, orders, and customers.

\- Identify the top 10 products by sales.

\- Analyze sales across countries.

\- Study monthly sales trends using visualizations.



\## Technologies Used

\- Python

\- Pandas

\- Matplotlib

\- Seaborn

\- Excel dataset

\- Git and GitHub



\## Dataset

The project uses the UCI Online Retail dataset containing online transaction records.



\## Data Cleaning

\- Removed duplicate records.

\- Removed rows missing product descriptions or customer IDs.

\- Excluded cancelled invoices.

\- Removed records with non-positive quantities or prices.

\- Calculated sales using Quantity × UnitPrice.



\## Key Results

\- Total sales: £8,887,208.89

\- Total orders: 18,532

\- Total customers: 4,338

\- Cleaned records: 392,692



\## Visualizations

\- `top\_products.png` — Top products by sales

\- `country\_sales.png` — Sales by country

\- `monthly\_sales.png` — Monthly sales trend



\## How to Run

1\. Install Python.

2\. Install the required libraries:

&#x20;  `pip install pandas matplotlib seaborn openpyxl`

3\. Place `Online Retail.xlsx` in the project folder.

4\. Run:

&#x20;  `python retail\_analysis.py`



\## Conclusion

This project demonstrates how Python can be used to clean retail data, calculate business metrics, and visualize sales trends for data-driven decision-making.
